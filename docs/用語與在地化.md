# 用語與在地化

本專案面向臺灣玩家，以正體中文與臺灣華語撰寫介面、程式註解及文件。這份指引統一專案自己的用字，不是政治立場宣示，也不表示其他華語地區用法錯誤。

## 編輯原則

1. **先看語境，再決定用字。** 詞庫命中是覆核線索，不是自動改寫命令。先辨別領域、義項、句子作用，再採用符合臺灣慣用語且不改變原意的寫法。
2. **寧可少改，不要誤改。** 尤其是法律程序、政治主張、歷史事件名稱、政黨全名、引用文字與來源標題，保留其準確原貌。
3. **注意子字串誤判。** 例如「社群發文」含有「群發」字串，但意思不是大量傳送訊息；本專案改寫為「社群貼文」以避免歧義。不可只憑局部命中便替換整段文字。
4. **區分正式名稱與一般敘述。** 一般敘述統一寫「臺灣」；政黨、機關、作品名稱及來源標題則按正式名稱或原文保留，例如「台灣民眾黨」、「台灣綠黨」及研究標題中的「台灣」。政治語彙「台獨」亦不以字形正規化改動其語境。
5. **程式識別字不翻譯。** Rust API、欄位、CLI 旗標、檔名及引用的命令維持原樣；只調整玩家實際讀到的中文說明。

## 專案詞彙表

| 使用情境 | 本專案用語 | 編輯界線 |
| --- | --- | --- |
| 軟體、程式與程式碼 | 軟體、程式、程式碼、原始碼 | 硬體與軟體分別使用「硬體」、「軟體」。 |
| 資訊與資料 | 資訊、資料、資料庫 | 選民調查及歷史敘述中的資料一律稱「資料」；不把統計義項的正確用詞機械替換。 |
| 使用介面與檔案 | 使用者、命令列、設定、預設、檢視、儲存、範本 | 「命令列」是本專案採用的臺灣技術用語；「範本」用於政黨、情境及任務設定。 |
| 模型與技術術語 | 參數、陣列、字串、字元、執行、除錯 | 「參數」是本專案的技術慣例，不因詞庫對照而改成「引數」。 |
| 遊戲民調呈現 | 支持度、支持度變化、模擬民調 | 遊戲內候選人支持份額與變動使用「支持度」；「投票率」只指參與投票的人數比率。 |
| 民調種類 | 候選人選舉支持度、政府施政滿意度 | 候選人選票競爭與政府施政評價分開稱呼；未實作的民調面板須明確標示未建模，不以「信任」等資源指標代稱。 |
| 政策與司法敘述 | 政策落實、司法程序、刑事程序 | 「程序」指法律或行政流程；「程式」才指電腦程式。政策用「落實／推動」，不用商業借詞「落地」。 |
| 社會與組織 | 社區、社群、人際／組織網絡 | 「社區」指地方生活場域；「社群」指共同興趣或線上群體。「網路」多用於網際連線；「網絡」可用於人際或組織關係。 |
| 政黨與制度名稱 | 官方全名、歷史時期慣稱 | 政黨名稱依正式寫法保留「台」或「臺」；法規名稱、歷史口號及當事人原話不任意改寫。 |

## 經詞庫掃描後保留的語境用字

逐檔掃描會找到候選字詞，但其中包含合法用法、專有名詞及子字串命中；以下詞彙已讀完整句確認，不採用機械替換：

| 命中詞 | 本專案語境 | 決定 |
| --- | --- | --- |
| 命令 | 「命令列」介面 | 保留「命令列」，不改成「指令列」。 |
| 參數 | 遊戲模型的可調係數、CLI 輸入 | 保留「參數」，是本專案技術用語。 |
| 程序 | 司法、立法或行政流程 | 保留「程序」，不可誤改成電腦「程式」。 |
| 協議 | 「兩岸經濟合作架構協議」正式名稱 | 保留名稱中的「協議」。 |
| 社區 | 地方生活場域、社區走訪 | 保留「社區」；只有群體或線上互動語境才用「社群」。 |
| 網絡 | 地方組織或宗教關係 | 保留關係網絡義；網際連線則用「網路」。 |
| 設置 | 法規或大學自治語境中的機構設置 | 保留「設置」；軟體設定使用「設定」。 |
| 代碼 | 縣市代碼 | 保留「代碼」，不改為「程式碼」。 |
| 資源配置 | 人力、預算等資源分配 | 保留「配置／分配」；軟體 configuration 才用「設定」。 |
| 圖像 | 附件中的靜態影像素材 | 保留「圖像」；影片與視訊依媒體型態分別用詞。 |
| 未通過 | 罷免投票結果未達法定門檻 | 保留「通過」的「通行／達成門檻」義，不改成「透過」。 |
| 社會安全網 | 社會福利與服務體系 | 整詞保留；不能因含有「全網」字串而改寫。 |
