# 使用說明

本文件整理玩家常用操作與命令列參數。完整參數提示可在終端機執行 `project-twn --help` 或 `cargo run -- --help` 查看。

## 遊戲操作

一般單場競選共 12 週、84 個每日行動。開始時會顯示玩家角色、操控的虛構候選人或政黨情境代表，以及其他競爭者。每日狀態列以「候選人支持度」呈現候選人間的對比盤勢；全國情境另列「政黨票支持度」，估算不分區政黨票情境，兩者分開計算。地方候選人選舉沒有另設政黨票支持度。`p` 可展開候選人、政黨票、分眾、互比、政府施政滿意度與議題指標。所有數值都是遊戲狀態，不是當期民調；玩家可見的候選人、組織、地方、事件、票數與結果皆為虛構設定。

每日操作採分層選單：先選行動分類，再選該類行動。輸入下列指令：

| 輸入 | 功能 |
| --- | --- |
| `?` | 顯示操作方式 |
| `r` | 執行策略引擎推薦的行動 |
| `d 編號` | 查看行動說明、模型效果與風險，再決定是否執行 |
| `p` | 檢視候選人支持度、政府施政評價、議題指標、分眾及互比試算 |
| `b` | 返回上一層分類 |
| `q` | 提前結束本場；確認後結算 |

行動前顯示的是規則模型的一步預估，執行後呈現含固定 seed 隨機波動與對手回應的實際遊戲變化。資源不足或超出行動限制時，引擎會拒絕該行動並保留當日回合。

使用純文字標記維持跨終端可讀性：`▶` 表示玩家候選人／政黨，`★ 推薦` 表示策略引擎首選，`✓【已選】` 表示剛執行的每日行動；每週結束會顯示一週支持變化、相對盤勢、信任與施政滿意度變化。終端顏色不是必要提示，因此關閉色彩或輸出到檔案時仍能讀懂。

## 模式與情境

| 模式 | 用途 |
| --- | --- |
| 全國選戰 | 使用虛構的年度候選人、政黨與起始支持情境。 |
| 地方選舉 | 以 `--year 2026 --region 地區` 選擇 22 個虛構地區之一；前輪政黨與支持值均為遊戲設定。地方陳情、志工協作、資訊查證與查核揭露會累積不同角色記憶；每三週回訪一次，地區議題也會改變角色與劇情細節。 |
| 第三勢力 | 地方模式可加 `--party 政黨`，扮演虛構政黨／地方聯盟範本；執政方須符合該地設定的上一輪執政聯盟。 |
| 黨內初選 | `--primary` 先進行四回合虛構提名流程，再進入大選。 |
| 幕僚模式 | `--staffer` 扮演競選團隊幕僚，處理競選主軸、週會議與每日劇情；選擇會影響居民、地方聯絡人、記者及總幹事的關係回訪，未處理的居民承諾會留到後續追蹤。此單場模式目前不支援 `--batch` 或 `--primary`。 |
| 人民罷免 | `--recall` 開啟獨立罷免戰役，可選提議／連署方或反對方；虛構選區採提議、有效連署及投票雙門檻流程，不含彈劾。人物關係會記住居民回訪、志工協作與資訊查證；誠信違規會影響後續信任連動與故事收束。 |

### 存檔續玩與候選人名冊

互動式候選人、幕僚與罷免單場可用 `--save 檔案.tsv` 保存進度，系統在開場與每次有效選擇後更新版本化存檔。再次執行 `--load 檔案.tsv` 會依原設定和固定 seed 重播決策並接續遊玩；目前自動示範及批次模式不支援存檔。存檔是可讀的 TSV 決策紀錄，請勿手動修改欄位或版本標頭。

```sh
project-twn --year 2024 --role challenger --seed 42 --save campaign.tsv
project-twn --load campaign.tsv
project-twn --recall --recall-side initiator --seed 42 --save recall.tsv
```

候選人名冊可自行建立 2–5 位候選人，使用遊戲內建的虛構政黨，並設定姓名、起始支持度與玩家席位：

```sh
project-twn --roster-editor roster.tsv
project-twn --year 2024 --role challenger --roster roster.tsv
```

名冊僅限互動單場總統或地方選舉，不適用於初選、罷免或批次模擬。自訂姓名與政黨會顯示於本場開票；遊戲資料仍不會被覆寫。

執政／連任角色以 `--role incumbent` 指定，在野挑戰角色以 `--role challenger` 指定。互動單場省略角色時會詢問選擇；批次模式必須指定角色。

## 常用指令

以下命令假設已下載對應平台版本；使用 Cargo 時在命令前加上 `cargo run --`。

```sh
# 查閱虛構選戰情境、地方及政黨清單（--history 為相容別名）
project-twn --scenarios
project-twn --regions
project-twn --parties

# 一般候選人模式
project-twn --year 2024 --role challenger --seed 42

# 幕僚模式
project-twn --year 2024 --role challenger --staffer --seed 42

# 人民罷免模式（完全虛構盤型）
project-twn --recall --recall-side initiator --recall-template low-turnout --seed 42
project-twn --recall --recall-side opposition --recall-template high-mobilization --auto --seed 7

# 霧川市地方選舉，以山海自治黨情境參選
project-twn --year 2026 --region 霧川市 --role challenger --party 山海自治黨 --seed 7

# 選擇難度、事件包及日期映射時序
project-twn --year 2024 --role challenger --difficulty story --event-pack democracy --timeline date

# 自動示範一場並記錄戰績
project-twn --year 2024 --role challenger --auto --seed 42 --log campaign.tsv
```

`--seed` 固定隨機起點，方便重現同一盤面。年份可用 1996–2026；地方情境目前限 2026。

## 情境設定參數

| 參數 | 可用值／用途 |
| --- | --- |
| `--year 年份` | 選擇總統年份或地方情境年份（1996–2026）。 |
| `--role incumbent\|challenger` | 執政／連任方或在野挑戰方。 |
| `--style balanced\|policy\|organizer\|communicator` | 能力風格：均衡、政策、組織或溝通。 |
| `--strategy balanced\|persuasion\|issue\|mobilization\|trust\|sustainable\|hardball` | 策略引擎權重組合。 |
| `--difficulty story\|standard\|hard` | 故事、標準或挑戰難度，影響開局及週資源。 |
| `--event-pack all\|democracy\|cross-strait\|local\|media` | 全部、公民參與、區域安全、地方民生或媒體信任事件包。 |
| `--timeline weekly\|date` | 依固定 seed 週次排程，或將虛構事件日期錨點映射至戰役週次。 |
| `--region 地區` | 選擇地方模式。搭配 `--regions` 查看虛構地區清單。 |
| `--party 政黨` | 地方模式的政黨情境範本。搭配 `--parties` 查看清單。 |
| `--primary` | 加入黨內初選流程。 |
| `--staffer` | 使用幕僚模式。 |
| `--recall` | 使用人民罷免獨立模式；不與一般選舉、幕僚或初選參數併用。 |
| `--recall-side initiator\|opposition` | 罷免提議／連署方或反對罷免方；省略時互動選擇。 |
| `--recall-template fictional\|low-turnout\|concentrated\|high-mobilization` | 選擇目標、政黨、選區與議題各異的虛構盤勢。 |
| `--roster 名冊.tsv` | 套用由 `--roster-editor` 建立的虛構候選人名冊（單場總統／地方選舉）。 |
| `--roster-editor 名冊.tsv` | 建立或編輯候選人名冊；請獨立執行，不要同時提供 `--roster`。 |
| `--save 存檔.tsv` | 對互動單場定期保存決策日誌，可用於候選人、幕僚及罷免模式。 |
| `--load 存檔.tsv` | 重播並接續既有互動戰役；使用時不搭配其他模式設定。 |
| `--auto` | 依策略引擎逐日選擇推薦行動。 |
| `--seed 整數` | 指定可重現的亂數種子。 |
| `--log 檔案.tsv` | 將單場結果追加到 TSV 戰績檔。 |

日期映射是可切換的虛構遊戲排程；未排到事件的週次會保留空白。

罷免模式中，不實連署及死亡連署是違規高風險遊戲選項，不會計入有效連署；若查核揭露會造成信任與資源懲處。系統不提供真實名冊或操作流程。

總統情境結算會顯示 22 個虛構地區的逐區領先者、投票率及累計票數，並另外列出政黨票與 34 席不分區席次估算；地方選舉只結算所選虛構地區。各項數字均為固定 seed 的遊戲情境結果，並非實際開票或民調預測。

## 批次模擬與測試工具

批次模式會自動推進遊戲，須明確指定 `--role`。一般批次上限為 10,000 場；比較及敏感度模式另有較低上限。

```sh
# 固定策略下跑 1,000 個 seed，並輸出逐場資料
project-twn --batch 1000 --year 2024 --role challenger --seed 1000 --batch-log runs.tsv

# 比較四種能力風格或七種策略權重
project-twn --batch 100 --year 2024 --role challenger --seed 1000 --sweep-styles
project-twn --batch 100 --year 2024 --role challenger --seed 1000 --sweep-strategies

# 進行單因子敏感度或雙因子交互作用檢視
project-twn --batch 100 --year 2024 --role challenger --seed 1000 --sensitivity
project-twn --batch 10 --year 2024 --role challenger --seed 1000 --interaction-sensitivity
```

`--sweep-styles`、`--sweep-strategies`、`--sensitivity` 與 `--interaction-sensitivity` 是分開執行的比較模式，不可互相併用。需保存逐場結果時加上 `--batch-log 檔案.tsv`。敏感度工具衡量遊戲規則對人為參數擾動的反應，不是實證校準或真實選舉因果分析。詳細策略含義及模型限制請見[策略系統](策略系統.md)與[驗證與評測](驗證與評測.md)。
