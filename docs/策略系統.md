# 策略系統與遊玩指南

## 設計原則

遊戲讓玩家比較在任方的施政責任與在野方的動員、監督和協調，但不把任何真實政黨設定成必勝角色。有效策略需要在民調、信任、動員、體力與預算間取捨；只追求短期支持度可能耗盡資金、體力或公信力。歷史事件只提供議題背景，結果由玩家選擇的回應與模擬參數決定。

## 策略引擎與行動預估

`GameState::preview_action()` 在不改變遊戲狀態、不消耗亂數的前提下，預估一項合法行動的一步效果：直接支持度變化、事件／地方契合、期望協調移轉、對手平均反應，以及信任、投票動能、體力和預算變化。隨機微幅波動的期望值設為 0；協調以目前成功率乘上平均移轉率；對手回應採設定區間中點。這些值是本模型的期望，不是實測民調。

`StrategyEngine` 用可組合的 `StrategyModule` 將預估拆成八個分項：

| 模組 | 評估內容 |
| --- | --- |
| 支持度影響 | 預估直接、協調及對手回應後的支持度淨變化。 |
| 議題脈絡 | 行動是否回應本週事件或地方議題焦點。 |
| 信任修復 | 依目前信任水準評估行動提供的信任資產。 |
| 投票動員 | 評估動員動能，決戰期提高其策略權重。 |
| 每週任務 | 評估是否推進或完成當週任務。 |
| 資源續航 | 依剩餘預算及體力評估成本與恢復。 |
| 誠信風險 | 評估負面操作的揭露機率與期望懲處資源。 |
| 組織基礎 | 依剩餘競選週數評估總部／後援會的地面量能效益。 |

七種策略只是對上述模組套用不同權重：

| 策略 | 優先考量 |
| --- | --- |
| `balanced` 均衡 | 平衡八個模組。 |
| `persuasion` 支持拓展 | 優先看支持度淨變化。 |
| `issue` 議題回應 | 提高事件和地方焦點契合。 |
| `mobilization` 投票動員 | 強調動員資產，競選末段權重增加。 |
| `trust` 信任修復 | 以信任偏低情境提升信任行動。 |
| `sustainable` 資源續航 | 重視預算與體力的持續性。 |
| `hardball` 高壓攻防 | 偏重短期支持變化、降低誠信風險權重；仍會把揭露後果計入支持度預估。 |

互動模式按策略分數排序顯示所有合法行動；玩家仍可自行決定，不會被鎖定。`--auto` 選擇最高分行動，`--sweep-strategies` 以同一 seed 比較七策略。行動後同時顯示模型期望變化與實際民調前後差，差異反映波動、對手反應、協調結果及是否遭查核；策略分數和支持度變化都只描述遊戲模型，不是經資料校準的選舉預測。

## 正面、中立與負面選戰行動

| 類別 | 行動範圍 | 模型效果 |
| --- | --- | --- |
| 正面選戰 | 一次性成立競選總部、成立後援會、志工逐戶拜票、地面團隊掃街發文宣、候選人掃街、支持者動員、弱勢關懷、勘災與災後關懷。 | 總部增加 35 點、後援會增加 20 點地面調度量能；地面行動以量能換取小幅支持／動員加成。關懷服務及勘災連結公共衛生、地方及治理議題。 |
| 中立／公共溝通 | 電視辯論、媒體專訪、政見發表、查證澄清、拜訪宗教團體、公開遶境與彌撒活動。 | 以政策說明、公開溝通與社區接觸為主。宗教活動不把信眾假定成同一政治群體，也不保證支持轉移；效果仍受能力、事件／地方焦點及遊戲波動影響。 |
| 負面／高風險 | 造假民調、匿名黑函／未查證指控、協調式網路輿論操作。 | 顯示每次操作的揭露率與期望懲處成本。抽中揭露時扣除遊戲預算並降低支持、信任及投票動能；累計揭露和重複操作都提高後續風險。單場與批次紀錄會保存揭露次數及懲處資源。 |

以上機率、支持幅度、懲處點數與組織加成都只是玩法平衡常數，不是現實世界的違法判定、執法統計或政治效果估計。預覽計算懲處的機率加權期望，實際行動才用固定 seed 抽取是否揭露。

## 兩種角色的資源循環

### 執政／連任方

- 適合累積可檢驗的政策進度、危機應變、透明報告與民生服務。
- 可用施政和公共服務回應績效與生活成本，也可透過透明說明經營信任。
- 若只重複施政型行動，可能忽略媒體信任、地方傾聽及跨黨溝通；行動多樣度也會偏低。

### 在野挑戰方

- 適合用社區走訪聆聽需求、政策論壇比較方案、監督提案與依法和平集會凸顯議題。
- 動員行動可以提升參與動能，但相對體力成本較高；適度休息能持續競選。
- 單靠抗議或批評不等於勝選：具體替代政策、可信度、地方組織和選民投票意願都重要。

## 十二週節奏

| 週次 | 顯示階段 | 策略提示 |
| --- | --- | --- |
| 1–4 | 布局期 | 維持體力、建立主軸、了解地方與選民原型，避免過早耗盡資源。 |
| 5–8 | 議題攻防期 | 用政策、監督或透明回應連結當週事件焦點；觀察分眾支持，而不只看總體數字。 |
| 9–12 | 決戰期 | 平衡動員與體力，視多候選人局勢嘗試互比／跨黨整合，保留資源給關鍵日。 |

以上是方便玩家思考的策略建議；階段名稱目前沒有獨立數值加成。

## 每週戰役任務（新增節奏）

每週有一項陣營專屬任務，從 4 個任務範本依 seed 洗牌抽出；同一任務不會連續兩週出現。大多數任務要求在七天中完成兩項相符行動，任務內容和進度會在每日畫面顯示。成功可得到最多 1 點預算；單週一次、預算上限 120，不會溢出或重複領取。任務失敗沒有懲罰，避免玩家被迫採取與局勢不合的行動。

執政方任務涵蓋政策交付、公開說明、地方服務及競選續航；挑戰方任務涵蓋社區動員、政策替代方案、監督說明及續航。最優策略不一定是追任務：若目標行動無法負擔、事件議題不合或體力不足，可以放棄任務並優先處理選戰局勢。引擎的任務模組只提供一項策略分數，任務權重低於或其他盤面因素更重要時，自動模式可能選擇不符合任務的行動。

## 民調協調與黨內初選

對比式民調看多位候選人同一題的支持度；互比式民調把未表態者以平均比例分配，計算候選人兩兩競爭情境。真實民調會按問法、樣本、交叉資料、投票意願和權重採不同方法；本作互比只是透明易懂的示範模型，不替代民調公司方法。

多候選人競選時，週限定民調協調行動可檢視總體支持和模擬互比，再嘗試把最弱候選人的一部分支持整合到玩家。跨黨協商另依政黨的藍綠、經濟、兩岸、宗教網絡等設定軸推估合作難度。未協調成功只表示模型擲出的情境結果，不等於某黨拒絕或某群選民拒絕。

`--primary` 先跑四回合虛構初選，政策派、組織派、溝通派可分別用自身行動爭取提名，也可使用對比／互比或整合協商。初選勝出者的路線會轉成大選能力風格；三位參賽者及起始支持率均為玩法設定，非歷史真實候選人初選或民調。

## 第三勢力及地方盤面

親民黨、新黨、台聯、時代力量、社會民主黨、台灣綠黨、勞動黨、民國黨／國會政黨聯盟、民眾黨等是跨年代、多議題的政治角色。政黨範本是協調系統用的簡化參數，不能當作各黨永久標籤或固定聯盟。角色、年份與議題情境不同，合作收益和談判成本也會不同。

地方模式有 22 個縣市首長情境；現任政黨參照 2022 年縣市長選舉，情境支持度及地方議題焦點屬遊戲設定。選 2026 年地方模式時，可挑戰、扮演上屆執政範本或以第三勢力探索小黨分票／整合。地方模式不是縣市分層回測，也沒有地方議員席次制度。

## 可操作小建議

1. 固定 seed 跑多場，只改變一到兩個策略變項，觀察平均與波動，避免根據一場結果下定論；再比較「追每週任務」與「依局勢自由行動」兩種策略。
2. 留意分眾支持：同一行動可讓議題相符的選民原型反應較強，卻不一定提升所有群體。
3. 保留體力與預算餘裕。每週補給有上限，因此連續高支出不會自動補足缺口。
4. 第三勢力可比較「維持獨立競爭」與「協調整合」兩種路線；模型轉票率很低且不代表現實轉移率。
5. 事件卡回應會稍微影響模擬支持與操作評分；卡片本身不指定哪個陣營得利。

### 批次比較

可用 `cargo run -- --batch 1000 --year 2024 --role challenger --seed 1000 --sweep-styles --batch-log batch.tsv`，以同一組 seed 比較四種能力風格；或 `cargo run -- --batch 100 --year 2024 --role challenger --seed 1000 --sweep-strategies --batch-log strategies.tsv` 比較七種策略引擎權重組合。策略批次由引擎每一天重新依局勢排名並選第一項合法行動，輸出 seed 勝出比例、模型內平均勝率、終局支持分位數、平均票差、任務達成數、揭露懲處、剩餘預算／體力及正／中／負行動構成。另列出八策略軸對「被選行動分數」的平均加權貢獻；41 欄 TSV 每場另以 `action_composition` 欄記錄逐項行動次數，方便重算。這些是排序分解，不是實際民意效果、勝選機率或因果貢獻。改變 `--year`、`--region`、`--party` 或 `--role` 時，應視為另一個情境組，不要混在同一結論中。

能力風格比較的是能力組合在固定策略權重下的模型輸出；策略比較的是權重差異下，行動引擎每一天重新選擇的結果。兩者都不是不同真實玩家策略成效的通用結論。跨 seed 的結果能呈現此模型的隨機波動，不能證明模型符合現實選舉。

## 尚未校準的策略假設

進階檢查可用 `cargo run -- --batch 100 --year 2024 --role challenger --seed 1000 --sensitivity --batch-log sensitivity.tsv`。工具以同一組 seed 比較基準與 7 個倍率各自的 0.8×／1.2×，輸出終局支持及模型內勝率的配對變化；`--region 臺北市 --year 2026` 可檢視地方焦點加成。這種擾動只回答「目前規則對此參數有多敏感」，不回答哪個值符合真實選舉。

要檢查參數組合，可用 `cargo run -- --batch 10 --year 2024 --role challenger --seed 1000 --interaction-sensitivity --batch-log interactions.tsv`。此模式對 7 個參數的 21 組配對各跑四個 0.8×／1.2×角點，並以相同 seed 計算終局支持和模型內勝率的差中差（ΔΔ）；每個 seed 84 場、最多 100 個 seed。ΔΔ 偏離零表示在目前模型設定和測試範圍內存在交互反應，不代表真實世界因果，也不代表這些倍率已經校準。

目前所有行動 swing、協調機率、事件加成、體力成本、每週資金及末段抽樣範圍都是明確遊戲常數。除歷史票數外，它們沒有從歷次競選活動紀錄或調查樣本估計。平衡修改須透過[評測與驗證流程](驗證與評測.md)，而不是只憑「看起來公平」直接宣稱已驗證。
