# Project-TWN｜臺灣選戰模擬器

以 Rust 撰寫的繁體中文命令列選戰模擬器。以臺灣歷屆總統直選結果、2022地方首長政黨版圖及重要公共事件為背景，提供「尋求連任／執政方」及「在野挑戰方」玩法，另有黨內初選與22縣市地方情境。

## 快速開始

需要 Rust stable（edition 2021），不依賴第三方 crate。

```powershell
cargo run -- --history
cargo run -- --simulate 2024 --role challenger --seed 42
cargo run -- --year 2026 --region 臺北市 --role challenger --seed 7 --auto
cargo run -- --year 2026 --region 高雄市 --primary --seed 7
cargo run -- --regions
```

省略 `--role` 時會互動選擇陣營；省略 `--auto` 時可逐週選擇行動。`--primary` 會先進行四回合黨內提名模擬，再進入大選。

## 遊戲方式

- 十二週競選、分為布局／議題攻防／決戰三階段；起始預算 100，每週最多補給 8、資金上限 120。行動也消耗體力，休息可恢復。
- 可選均衡、政策、組織、溝通四種玩家能力風格；能力值只屬遊戲設定，不是對真實候選人的歷史評分。
- **執政／連任方：**施政方案落地、公共危機應變、公開施政檢討、地方民生服務。行政表現、公開程度與議題契合度會影響模擬民調。
- **在野挑戰方：**社區走訪、政見論壇、依法集會、跨黨協調、監督提案。政策溝通、組織動員及公民行動會影響模擬民調。
- 每週也會有小幅、固定 seed 的對手回應；信任指數與動員指數會納入回合及終盤計算。
- 公共事件提供議題背景，不預先指定任何政黨的受益或受損方向；採取與事件議題相符的行動才會得到額外模擬加成。
- 三人以上競爭時可查看「對比式」多候選人支持度與「互比式」簡化對戰情境，並可選擇整合協商行動；缺乏交叉樣本資料時，互比模型將其他候選人支持各半轉移，不假裝成真實民調。
- 結算顯示一次情境開票、1,200 次終盤誤差抽樣的玩家勝率，以及政策、信任、動員、議題回應、資源管理、行動多樣度六軸戰役檢討雷達。可用 `--log campaign-history.tsv` 累積戰績，或透過 seed 重現同一場模擬。所有數值皆為遊戲模型結果，不是民調預測。

## 地方與初選模式

- `--regions` 列出22縣市；`--region 臺北市` 等選項可進入 2026 地方首長情境。上屆政黨參照 2022 地方選舉結果；起始支持度與地方議題權重屬於遊戲平衡設定，並非官方得票或縣市民調。
- `--primary` 提供政策派、組織派、溝通派三條虛構提名路線及四回合策略選擇。每回合會並列多候選人支持度和兩兩互比；提名結果決定後續玩家能力組合。
- 「韓流」做為2018地方選舉的歷史事件卡；2026「洋流」做為正在形成的選戰敘事／公民參與議題卡。媒體與研究對這些現象有不同解讀，事件卡不把任何一方設定為固定受益者。

## 歷史資料範圍

- 收錄 1996–2024 年八次總統、副總統直選的候選人、政黨、得票數及得票率；另有 2016、2024 年立法院席次，以及 2022 年 22 縣市首長政黨作地方模式參照。這是選戰模擬所需的精選整理，不是逐選區的完整選舉資料庫。
- 2026 年地方公職人員選舉投票日為 **2026-11-28**。截至 **2026-11-08** 尚無選舉結果；無地區的 2026 全國代理情境以 2024 總統票作起點，地方模式則參照各地 2022 首長政黨與獨立情境參數，皆不代表地方候選人或民調。
- 疫情事件卡保留時間先後：臺灣首例 COVID-19 境外移入確診於 2020-01-21 公布，晚於 2020-01-11 總統投票日，因此不當成 2020 年總統選舉的選前因素。

重要背景包括三一九槍擊案、陳雲林來台爭議、反媒體壟斷運動、太陽花學運、反課綱微調運動、2018韓流、民進黨首次同時取得總統職位與國會多數、同性婚姻法制化、COVID-19 疫情治理、2022地方選舉、2024三黨不過半國會及2026洋流討論。年表、來源與各事件的時序說明見 [`docs/歷史與來源.md`](docs/歷史與來源.md)。

## 開發與測試

```powershell
cargo fmt --check
cargo test
cargo run -- --history
cargo run -- --regions
cargo run -- --year 2026 --region 臺北市 --role challenger --seed 42 --auto
```

資料型別與歷史資料在 `src/history.rs`；行動、民調更新、動員效果與結算模型在 `src/sim.rs`；命令列互動在 `src/main.rs`。來源與設計假設在 `docs/`。
