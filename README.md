# Project-TWN｜臺灣選戰模擬器

> 以 Rust 打造的虛構選戰策略遊戲，包含全國與地方選舉、候選人與幕僚模式、多週故事及人民罷免模式。

Project-TWN 是一款以臺灣政治環境常見的選舉制度與公共議題類型為靈感的命令列策略遊戲。玩家可以操作虛構候選人或競選幕僚，在 12 週的競選期間安排每日行動、回應事件、管理團隊資源，並探索不同選擇如何改變遊戲中的支持度與故事走向。

玩家可見的候選人、政黨、團體、地方、事件、票數及結局皆為虛構遊戲設定。支持度、行動效果及勝負由遊戲規則計算；本作不是民調預測器。

## 開始遊玩

- **下載測試版：**[GitHub Releases](https://github.com/popuchoco/Project-TWN/releases)
- **自行建置：**需要 Rust stable（edition 2021）。

```sh
cargo run -- --help
cargo run -- --year 2024 --role challenger --seed 42
```

直接啟動下載的執行檔會先顯示遊戲模式選單，可選候選人、幕僚或人民罷免模式；也可用 `--staffer` 或 `--recall` 直接指定模式。

互動主控台會在正常結束、錯誤或 panic 後等待按 Enter 再關閉；`--version` 可查看版本／commit。互動選單遇到輸入結尾會安全離開；若搭配 `--save`，可用 `--load` 接續。

也可以試試地方選舉或幕僚模式：

```sh
cargo run -- --year 2026 --region 霧川市 --role challenger --party 山海自治黨 --seed 7
cargo run -- --year 2024 --role challenger --staffer --seed 42
```

互動遊戲先選行動分類，再選具體行動；輸入 `?` 查看操作說明、`r` 採用策略推薦、`d 編號` 檢視行動詳情、`p` 展開支持度資訊、`b` 返回上一層。輸入 `q` 提前結束時會再次確認。

## 遊戲內容

- 12 週、84 天的競選流程；管理預算、體力、信任與動員。
- 執政／連任方與在野挑戰方的差異化玩法，另有 22 個虛構地方情境及黨內初選。
- 候選人模式與幕僚模式：每日行動、策略排序、週任務、事件回應與多週分歧故事。
- 人民罷免模式：虛構目標與選區、提議／連署／投票三階段及罷免／反罷免雙方策略；不含彈劾。
- 難度、事件包、時序及政黨情境選項，支援固定 seed 重現遊戲。
- 批次遊玩、策略比較與模型敏感度工具，供開發及平衡測試使用。
