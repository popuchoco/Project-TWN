# Project-TWN｜臺灣選戰模擬器

> 以 Rust 打造的臺灣選戰策略遊戲，包含總統與地方選舉情境、候選人與幕僚模式、多週故事，以及可重現的策略模擬。

Project-TWN 是一款以臺灣民主發展、選舉情境與公共議題為素材的命令列遊戲。玩家可以操作候選人或競選幕僚，在 12 週的競選期間安排每日行動、回應事件、管理團隊資源，並探索不同選擇如何改變遊戲中的支持度與故事走向。

本作是策略遊戲，不是民調預測器。歷史得票與事件用來建立情境；支持度、行動效果及勝負則由遊戲規則計算。

## 開始遊玩

- **下載測試版：**[GitHub Releases](https://github.com/popuchoco/Project-TWN/releases)
- **自行建置：**需要 Rust stable（edition 2021）。

```sh
cargo run -- --help
cargo run -- --year 2024 --role challenger --seed 42
```

也可以試試地方選舉或幕僚模式：

```sh
cargo run -- --year 2026 --region 臺北市 --role challenger --party 時代力量 --seed 7
cargo run -- --year 2024 --role challenger --staffer --seed 42
```

互動遊戲先選行動分類，再選具體行動；輸入 `?` 查看操作說明、`r` 採用策略推薦、`d 編號` 檢視行動詳情、`p` 展開支持度資訊、`b` 返回上一層。輸入 `q` 提前結束時會再次確認。

## 遊戲內容

- 12 週、84 天的競選流程；管理預算、體力、信任與動員。
- 執政／連任方與在野挑戰方的差異化玩法，另有 22 個縣市地方情境及黨內初選。
- 候選人模式與幕僚模式：每日行動、策略排序、週任務、事件回應與多週分歧故事。
- 人民罷免模式：虛構目標與選區、提議／連署／投票三階段及罷免／反罷免雙方策略；不含彈劾。
- 難度、事件包、時序及政黨情境選項，支援固定 seed 重現遊戲。
- 批次遊玩、策略比較與模型敏感度工具，供開發及平衡測試使用。
