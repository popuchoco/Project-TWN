# Project-TWN｜臺灣選戰模擬器

以 Rust 撰寫的正體中文（臺灣用語）命令列選戰模擬器。以臺灣歷屆總統直選結果、2022 年地方首長政黨版圖及重要公共事件為背景，提供「尋求連任／執政方」及「在野挑戰方」玩法，另有黨內初選與 22 個縣市地方情境。

## 快速開始

需要 Rust stable（edition 2021），不依賴第三方 crate。

```powershell
cargo run -- --history
cargo run -- --simulate 2024 --role challenger --seed 42
cargo run -- --year 2026 --region 臺北市 --role challenger --seed 7 --auto
cargo run -- --year 2026 --region 臺北市 --role challenger --party 時代力量 --seed 7 --auto
cargo run -- --year 2026 --region 臺北市 --role challenger --strategy issue --seed 7
cargo run -- --year 2026 --region 高雄市 --primary --seed 7
cargo run -- --batch 1000 --year 2024 --role challenger --seed 1000 --sweep-styles --batch-log batch.tsv
cargo run -- --batch 100 --year 2024 --role challenger --seed 1000 --sweep-strategies --batch-log strategies.tsv
cargo run -- --batch 100 --year 2024 --role challenger --seed 1000 --sensitivity --batch-log sensitivity.tsv
cargo run -- --batch 10 --year 2024 --role challenger --seed 1000 --interaction-sensitivity --batch-log interactions.tsv
cargo run -- --regions
cargo run -- --parties
```

省略 `--role` 時會互動選擇陣營；省略 `--auto` 時可逐日選擇行動。`--primary` 會先進行四回合黨內提名模擬，再進入大選。

## 遊戲方式

這是一款以臺灣選戰與民主事件為題材的策略遊戲，不是選舉預測器或政治學教材。歷史資料用來提供情境、事件和陣營脈絡；支持度、行動收益、選民原型和事件加成是為了讓選擇有取捨、結果易理解且方便平衡的遊戲規則。設計優先順序是好玩、可讀、可重玩，不是擬合真實投票行為。

- 十二週競選，每週七天、共 84 次每日行動決策，分為布局／議題攻防／決戰三階段；起始預算 100，每週最多補給 8、資金上限 120。行動也消耗體力，休息可恢復。
- 可選均衡、政策、組織、溝通四種玩家能力風格；能力值只屬遊戲設定，不是對真實候選人的歷史評分。
- **執政／連任方：**政策落實、公共危機應變、公開施政檢討、地方民生服務。行政表現、公開程度與議題契合度會影響模擬民調。
- **在野挑戰方：**社區走訪、政見論壇、依法集會、跨黨協調、監督提案。政策溝通、組織動員及公民行動會影響模擬民調。
- 連任／執政方可選擇行政施政、透明說明、民生服務與危機應變；在野方可做地方走訪、政策監督、和平集會與動員。兩種角色都需管理每日行程、體力、預算和信任。
- 共通行動分為三類：**正面選戰**包含成立競選總部／後援會、志工與地面團隊、發文宣、掃街、支持者動員、弱勢關懷和勘災；**中立選戰**包含辯論、媒體專訪、政見發表、宗教團體拜訪、遶境及彌撒等公開活動；**負面／高風險選戰**以抽象遊戲行動呈現造假民調、匿名黑函與協調式輿論操作。宗教活動不預設信眾立場或保證轉票。
- 總部與後援會各可成立一次，形成地面調度量能，提升後續掃街、文宣與動員效果。負面操作有可見的預估揭露率與期望懲處成本；一旦遭查核，會扣除預算、支持度、信任及投票動能，重複使用會提高揭露風險，戰績亦記錄揭露次數與懲處資源。
- 每日行動會影響六種遊戲用選民原型：政黨認同／基本盤、中間游離、青年公民、地方民生、兩岸安全、平權公共服務。原型權重是為策略差異與可讀回饋設計，不是人口比例、實際民調或對某年齡／群體的刻板預測；各原型支持度可在週結算時檢視。
- 每週有小幅、固定 seed 的對手回應；信任、動員、分眾支持和終盤誤差抽樣共同影響模擬結果。
- 每週再抽一個陣營專屬「戰役任務」：例如交付政策成果、公開資訊、社區動員或競選續航。完成指定次數可獲最多 1 點預算，12 週任務會洗牌且避免相鄰重複；任務模組會把進度納入引擎評分，但是否追任務仍依所選策略與當下局勢決定。它提供短期策略節奏，不是現實政治建議。
- 公共事件提供議題背景，不預先指定任何政黨的受益或受損方向；採取與事件議題相符的行動才會得到額外模擬加成。
- 三人以上競爭時可檢視「對比式」多候選人支持度與「互比式」簡化對戰情境，並可選擇整合協商行動；缺乏交叉樣本資料時，互比模型將其他候選人支持各半轉移，不假裝成真實民調。
- `--parties` 列出政黨情境範本；地方模式可用 `--party` 扮演第三勢力。政黨之間以多個議題軸估算協商接近度，並非固定聯盟或永久意識形態標籤；每週可各做一次民調協調及跨黨協商。
- 結算顯示一次情境開票、1,200 次終盤誤差抽樣的玩家勝率、達成任務數，以及政策、信任、動員、議題回應、資源管理、行動多樣度六軸**戰役操作評分**。此評分回顧玩家的本場操作，不是遊戲品質評測或平衡驗證。可用 `--log campaign-history.tsv` 累積戰績，或透過 seed 重現同一場模擬。所有數值皆為遊戲模型結果，不是民調預測。

## 策略引擎

- 每個可用行動會先以當前支持度、分眾議題、週事件、地方焦點、信任、投票動能、體力、預算及週任務計算「一步期望效果」，策略模組再依偏好權重排序。
- 提供均衡、支持拓展、議題回應、投票動員、信任修復、資源續航及高壓攻防七種策略。排序模組一併評估組織基礎、負面操作揭露風險與懲處代價；互動模式並列分類、支持變化、信任／動員／體力、資源及風險估值。
- `--auto` 按所選策略的排序行動；`--batch ... --sweep-strategies` 以相同 seed 比較七種策略的支持、模型內勝率、票差及平均揭露／懲處，最多 1,000 個 seed。
- 行動前的支持變化是規則模型的一步期望估值，平均化隨機波動及協調成敗；行動後顯示實際模擬支持變化。兩者可能不同，因實際行動會抽取 seed 隨機波動、對手回應與協調結果。策略分數為玩法啟發式，不是經調查資料校準的民意預測或真實政治建議。

## 地方與初選模式

- `--regions` 列出 22 個縣市；`--region 臺北市` 等選項可進入 2026 年地方首長情境。上屆政黨參照 2022 年地方選舉結果；起始支持度與地方議題權重屬於遊戲平衡設定，並非官方得票或縣市民調。用 `--party 新黨`、`--party 社會民主黨` 等情境範本探索第三勢力。
- `--primary` 提供政策派、組織派、溝通派三條虛構提名路線及四回合策略選擇。每回合會並列多候選人支持度和兩兩互比；提名結果決定後續玩家能力組合。
- 「韓流」做為2018地方選舉的歷史事件卡；2026「洋流」做為正在形成的選戰敘事／公民參與議題卡。媒體與研究對這些現象有不同解讀，事件卡不把任何一方設定為固定受益者。

## 批次模擬與風格比較

- `--batch N` 以起始 `--seed` 起算，連續執行 N 個固定 seed 的策略引擎自動戰役；需明確提供 `--role`。一般模式最多 10,000 場。
- `--sweep-styles` 以相同 seed 範圍比較均衡、政策、組織、溝通四種能力風格，可用於策略敏感度探索；自動行動政策固定，因此結果只反映指定情境與示範策略，不代表人類玩家策略的普遍效果。
- `--strategy balanced|persuasion|issue|mobilization|trust|sustainable|hardball` 選擇策略引擎權重；單場互動會把所有合法行動依目前遊戲狀態排序，`--auto` 會採取最高分行動。
- `--sweep-strategies` 用固定能力風格與相同 seed 範圍比較七種行動策略；最多 1,000 個 seed，不能與 `--sweep-styles` 同時使用。摘要及 TSV 記錄策略名稱、負面操作揭露次數及懲處資源，方便重現比較。
- `--sensitivity` 做單因子模型參數測試：以相同 seed 對行動基礎效果、事件／地方加成、信任修正、疲勞懲罰、每日波動及終局誤差逐一測試 0.8× 與 1.2×；另有基準跑次作配對比較。此模式最多 1,000 個 seed，且不可和 `--sweep-styles` 同時使用。
- `--interaction-sensitivity` 以 0.8×／1.2× 組成 2×2 因子設計，逐一檢視七項模型參數的 21 組配對；每個 seed 跑 84 場，依終局支持與模型內勝率計算差中差（ΔΔ），最多 100 個 seed。這可指出目前規則中的參數交互作用，並不代表真實選舉因果或校準係數。
- `--batch-log runs.tsv` 會逐場追加 TSV 原始跑次，包含 seed、實際勝者、玩家終局支持與票差、模型內勝率、任務、剩餘預算與體力、誠信懲處、正／中／負行動數、逐項行動次數，以及八個策略軸的平均加權分數貢獻。新版欄位不相容時會拒絕混寫；請為新版格式另指定檔名。
- 一般摘要呈現各 seed 的實際勝出比例、模型內平均勝率、終局支持均值與 P10／P50／P90、平均票差、任務完成數、剩餘預算與體力、行動構成及策略模組貢獻；敏感度摘要則呈現相對基準的配對終局支持與模型內勝率變化。模組分數是引擎排序分數，不是行動收益機率；這些都是遊戲模型結果，不是民調或選舉預測。

## 歷史資料範圍

- 收錄 1996–2024 年八次總統、副總統直選的候選人、政黨、得票數及得票率；另有 2016、2024 年立法院席次，以及 2022 年 22 縣市首長政黨作地方模式參照。這是選戰模擬所需的精選整理，不是逐選區的完整選舉資料庫。
- 2026 年地方公職人員選舉投票日為 **2026-11-28**。截至 **2026-11-08** 尚無選舉結果；無地區的 2026 全國代理情境以 2024 總統票作起點，地方模式則參照各地 2022 首長政黨與獨立情境參數，皆不代表地方候選人或民調。
- 疫情事件卡保留時間先後：臺灣首例 COVID-19 境外移入確診於 2020-01-21 公布，晚於 2020-01-11 總統投票日，因此不當成 2020 年總統選舉的選前因素。

歷史事件涵蓋解嚴後校園自治與黨政軍影響退場、野百合學運、廢止《動員戡亂時期臨時條款》、刑法第100條修正、首次和平政黨輪替、拉法葉艦採購爭議、林益世案、三一九槍擊案、紅衫軍、ECFA、陳雲林來台與警力維安爭議、洪仲丘事件、反媒體壟斷、太陽花、周子瑜遭貼政治標籤與道歉影片、反課綱、李新死因影片與羅淑蕾名譽訴訟、愛國同心會與異議人士衝突及其成員參選個案、柯文哲與彭文正相關司法程序，以及轉型正義、香港運動、反滲透法、同性婚姻、COVID-19、韓流、2024三黨不過半及2025罷免投票。人物及司法事件明確區分指控、起訴、程序裁定和確定判決；不把案件簡化成固定政黨加減分。年表、來源與模型限制見 [`docs/歷史與來源.md`](docs/歷史與來源.md)。

## 開發與測試

```powershell
cargo fmt --check
cargo test
cargo run -- --history
cargo run -- --regions
cargo run -- --year 2026 --region 臺北市 --role challenger --party 時代力量 --seed 42 --auto
```

資料型別與歷史資料在 `src/history.rs`；行動、支持度更新、動員效果與結算模型在 `src/sim.rs`；模組化策略評分在 `src/strategy.rs`；命令列互動在 `src/main.rs`。系統設計與開發文件：[`遊戲架構`](docs/遊戲架構.md)、[`策略系統`](docs/策略系統.md)、[`系統開發紀錄`](docs/系統開發紀錄.md)、[`驗證與評測`](docs/驗證與評測.md)、[`歷史與來源`](docs/歷史與來源.md)、[`用語與在地化`](docs/用語與在地化.md)。
